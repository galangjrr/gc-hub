Titik Rawan 1: Kecurangan Operator Kasir

  • • Celah: Kasir membukakan sesi main tanpa mencatat uang sewa, atau me-refund sisa jam lalu mengantongi uangnya sendiri.
  • • Pengamanan GC-Hub: Setiap buka sesi dicatat di transaction_logs dan session_logs. Tutup shift kasir wajib mencocokkan fisik uang laci dengan laporan sistem.
  • • Ide Peningkatan: Pasang aturan wajib print struk fisik saat uang masuk atau integrasi CCTV counter kasir.

Titik Rawan 2: Pembobolan Bilik Komputer

  • • Celah: Pelanggan mencoba membongkar gembok layar bilik menggunakan Task Manager, CMD, tombol Windows, atau colok Flashdisk script.
  • • Pengamanan GC-Hub: Native hook WH_KEYBOARD_LL mematikan tombol Windows, Alt+Tab, dan otomatis membunuh proses taskmgr.exe.
  • • Ide Peningkatan: Aktifkan Windows Registry Policy untuk mengunci USB mass-storage saat PC dalam status terkunci (AVAILABLE).

Titik Rawan 3: Kebocoran Data Pelanggan

  • • Celah: Akun Steam, Discord, Google, dan file download pelanggan tertinggal di PC setelah waktu habis dan dipakai orang lain.
  • • Pengamanan GC-Hub: Saat sisa waktu 0 detik (Auto-Cutoff), server mengirim perintah pembersihan client:cleanupSession sebelum layar digembok.
  • • Ide Peningkatan: Integrasikan auto-restart PC bilik atau software restore (seperti DeepFreeze/Shadow Defender) setiap sesi berganti.
